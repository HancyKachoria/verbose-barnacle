# Instagram Portfolio

A modern portfolio website inspired by Instagram's design, built with React, TypeScript, and Tailwind CSS.

## Features

- Instagram-like UI with navbar, profile section, and post grid
- Interactive story highlights for showcasing skills
- Responsive design
- Smooth animations with Framer Motion
- TypeScript for type safety

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

## Customization

- Update the profile information in `src/App.tsx`
- Modify the portfolio items in the `posts` state
- Customize colors in `tailwind.config.js`
- Add your own images and content

## Technologies Used

- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Heroicons
- Vite
